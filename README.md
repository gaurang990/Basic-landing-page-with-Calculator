# 🌐 Basic Landing Page with Calculator

A simple and responsive **Landing Page with an integrated Calculator** built using **HTML, CSS, and JavaScript**. This project combines a modern landing page design with a functional calculator to demonstrate frontend development skills and JavaScript logic.

## 🚀 Features

* ✨ Clean and modern landing page design
* 🧮 Functional calculator
* ➕ Addition operation
* ➖ Subtraction operation
* ✖️ Multiplication operation
* ➗ Division operation
* 📱 Responsive design for different screen sizes
* 🎨 Custom styling using CSS
* ⚡ Interactive user interface using JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ⚙️ Installation & Setup

### Clone the repository

```bash
git clone https://github.com/gaurang990/Basic-landing-page-with-Calculator.git
```

### Navigate to the project folder

```bash
cd Basic-landing-page-with-Calculator
```

### Run the project

Open the `index.html` file in your browser.

No additional installation or server setup is required.
